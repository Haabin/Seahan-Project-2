# 운영 매뉴얼 (초안) · 주간 생산계획 수립 지원 툴

대상: 생산지원팀장(작성), 생산1팀·영업팀(조회), 운영 관리자(기준정보·계정)

## 1. 로그인

- 주소: 운영 관리자가 공유한 URL. 계정(이메일·비밀번호)은 관리자가 만들어 전달합니다. 자유 가입은 없습니다.
- 역할: **조회**(확정 계획 보기), **작성**(계획 입력·확정·변경, 업로드), **관리**(기준정보·설정·계정).

## 2. 목요일 가배대 작성 (작성자)

1. **계획 간트** 메뉴 → 상단에서 계획 시작 목요일 확인. 이전 확정 계획의 겹치는 날짜가 자동으로 이어져 있습니다.
2. 최신 **출고일정표**·**제품수불일보** 엑셀을 상단 「업로드」로 올립니다. 화면에 **데이터 기준 시각**이 표시됩니다.
3. 셀을 클릭해 금형(제품)·수량·교체 유형을 입력합니다. 허용되지 않은 금형은 목록에 나오지 않습니다.
   - 막대를 **끌어서** 다른 날짜로 옮기거나, 막대 **오른쪽 끝을 끌어** 연장합니다.
   - 수량을 비우면 예상 생산량(Capa × 계수)이 자동 적용됩니다. 셀을 누르면 계산 근거가 펼쳐집니다.
   - 제품이 바뀌는 날 교체 유형을 비워 두면 기본 교체유형(B/M)으로 계산되고 「미입력」 주의가 표시됩니다.
4. 오른쪽 **경고 목록**에서 제약 위반(빨강)·부족 품목·주의를 확인하고, 항목을 누르면 해당 셀로 이동합니다.
5. **수급 검증** 메뉴에서 제품별 재고 추이(빨강 부족 / 노랑 안전재고 미달 / 회색 과잉)를 확인합니다. 가중치 슬라이더로 정렬 기준을 조정합니다.
6. 「엑셀 내보내기」로 현행 양식 파일을 받아 메일로 공유합니다.

## 3. 금요일 확정과 주중 변경

- **확정**: 「확정 / 변경 저장」 버튼 → 첫 확정은 Rev 0으로 저장됩니다.
- **변경**: Rev 0 이후의 저장은 **변경 사유(구분 + 내용)를 입력해야** 저장됩니다. Rev 1, 2…로 쌓입니다.
- **Rev 이력** 메뉴에서 두 Rev를 골라 바뀐 셀을 비교합니다.
- 설비 고장 등 **가동 불가일**은 간트 상단 「가동 불가 등록」에서 호기·기간·사유를 등록합니다. 해당 셀은 빗금 처리되고 생산량 0으로 계산됩니다.

## 4. 씨벌크 원료 (작성자)

- **씨벌크 원료** 메뉴: 사일로 합계 재고 6주 그래프(상한 160톤, 하한은 설정값). 1~2주는 계획, 3~6주는 운용안 추정입니다.
- **발주 추천 카드**: 하한 미달 예상일에서 리드타임(30일)을 뺀 발주 기한과 추천 물량(22톤 단위)이 표시됩니다. 발주는 사람이 합니다.
- 발주 후 **입고 일정 추가**에 공급사·입고 예정일·수량을 등록하면 그래프가 다시 계산됩니다.
- 아침 실측 재고는 「실측 입력」에서 사일로별로 기록합니다.
- 계획 대상이 아닌 사출 설비(A1, 2공장)의 사용량은 「외부 설비 사용량」에서 평일/주말 톤을 조정합니다.

## 5. 기준정보 (관리자)

- **기준정보** 메뉴: 제품(Capa·중량·안전재고·단위), 호기별 허용 금형, 호기×제품 Capa, 교체 손실 계수, 설정값(주말 계수, 교체 한도, 사일로 하한 등), 계정 역할.
- **제품배치 운용안 엑셀 업로드**로 제품·허용 금형·Capa·월별 물량을 일괄 등록합니다. 파일에 등장한 호기만 교체됩니다.
- 모든 수정은 수정자·시각이 감사 로그에 남습니다.

## 6. 계정·백업 (관리자)

- 계정 생성: 개발 PC에서 `npm run create-user -- 이메일 비밀번호 역할 이름`. 또는 Supabase 대시보드 → Authentication → Users → Add user 후 기준정보 화면에서 역할 지정.
- 백업: Supabase 자동 일일 백업. 수동 백업은 README「백업」 참고.
- 기준정보 변경 절차: 변경 요청 → 관리자가 화면에서 수정 → 간트에서 재계산 결과 확인 → 필요 시 Rev 변경 저장(사유: 기타).

## 7. 자주 묻는 질문

| 질문 | 답 |
|---|---|
| 엑셀 가져오기에서 "매칭 실패" 셀이 나와요 | 기준정보의 제품명과 셀 글자가 다릅니다. 기준정보 제품명을 맞추거나 셀을 직접 입력하세요. |
| 사출기 행 숫자가 무시된다고 떠요 | 현행 계획표의 사출기 행(Q1)은 의미 확정 전이라 가져오지 않습니다. |
| 과잉이 너무 많이 떠요 | 기준정보 → 설정값 「과잉 기준 일수」(기본 14일) 또는 제품별 과잉 기준을 조정하세요. |
| 조회 계정으로 수정이 안 돼요 | 정상입니다. 조회 권한은 읽기 전용입니다. |
