# 운영 매뉴얼 (초안) · 주간 생산계획 수립 지원 툴

대상: 생산지원팀장(작성), 생산1팀·영업팀(조회), 운영 관리자(기준정보·계정)

## 1. 로그인

- 주소: 운영 관리자가 공유한 URL. 계정(이메일·비밀번호)은 관리자가 만들어 전달합니다. 자유 가입은 없습니다.
- 역할: **조회**(확정 계획 보기), **작성**(계획 입력·확정·변경, 업로드), **관리**(기준정보·설정·계정).

## 2. 목요일 가배대 작성 (작성자)

1. **생산계획표** 메뉴 → 상단에서 계획 시작 목요일 확인. 이전 확정 계획의 겹치는 날짜가 자동으로 이어져 있습니다.
2. 최신 **출고일정표**·**제품수불일보** 엑셀을 상단 「업로드」로 올립니다. 화면에 **데이터 기준 시각**이 표시됩니다.
3. 셀을 클릭해 금형(제품)·수량·교체 유형을 입력합니다. 허용되지 않은 금형은 목록에 나오지 않습니다.
   - 막대를 **끌어서** 다른 날짜로 옮기거나, 막대 **오른쪽 끝을 끌어** 연장합니다.
   - 수량을 비우면 예상 생산량(Capa × 계수)이 자동 적용됩니다. 셀을 누르면 계산 근거가 펼쳐집니다.
   - 제품이 바뀌는 날 교체 유형을 비워 두면 기본 교체유형(B/M)으로 계산되고 「미입력」 주의가 표시됩니다.
4. 오른쪽 **경고 목록**에서 제약 위반(빨강)·부족 품목·주의를 확인하고, 항목을 누르면 해당 셀로 이동합니다.
5. **수급 검증** 메뉴에서 제품별 재고 추이(빨강 부족 / 노랑 안전재고 미달 / 회색 과잉)를 확인합니다. 가중치 슬라이더로 정렬 기준을 조정합니다.
6. 「엑셀 내보내기」로 현행 양식 파일을 받아 메일로 공유합니다.

## 2-1. 과거 생산배대 가져오기 (작성자)

1. **생산계획표** → 「엑셀 가져오기」에서 현장 생산배대 파일(예: `26년 10월 5주간 생산배대 (Rev. 1).xlsx`)을 고릅니다. 파일 형식은 자동으로 판별합니다.
2. **미리보기**에서 원본이 표로 보입니다. 큰 네모 = Full set 교체, 작은 네모 = B/M 교체, 화살표 = 그 제품을 계속 생산하는 날입니다. 빈 칸은 대기입니다.
3. 주황색 제품명은 기준정보에 없는 이름입니다. 아래 목록에서 **기존 제품에 연결 / 새 제품으로 등록 / 건너뛰기** 중 하나를 고릅니다. 호기의 「생산 가능 금형」 목록이 참고로 표시됩니다.
4. Rev 번호는 파일 이름에서 읽습니다. 없으면 직접 입력합니다. 「확정 Rev로 저장」을 누르면 그 기간의 확정본으로 쌓입니다. 같은 번호가 이미 있으면 다음 번호가 됩니다.
5. 이렇게 저장한 확정 계획이 **초안 자동 생성의 과거 데이터**가 됩니다.

## 2-2. 주문 입력과 초안 자동 생성 (작성자)

1. **주문 입력** 메뉴에서 품명·수량·납기일·고객사를 넣습니다. 엑셀로 한꺼번에 올리려면 템플릿을 내려받아 채웁니다. 제품과 매칭되지 않은 주문은 빨갛게 표시되며, 그 자리에서 제품을 연결할 수 있습니다.
2. **생산계획표** → 「초안 자동 생성」. 
   - **빈 셀만 채우기**: 이미 넣은 셀은 그대로 둡니다. **전체 다시 만들기**: 초안을 비우고 다시 만듭니다(확인창).
   - **순 소요량**을 켜면 재고현황의 현재고(안전재고 제외)를 먼저 쓰고 모자란 만큼만 계획합니다.
3. 오른쪽 **확인 필요** 목록을 위에서부터 봅니다. 항목을 누르면 해당 셀로 이동합니다.

   | 표시 | 뜻 | 할 일 |
   |---|---|---|
   | 신규 제품 · 임시 배정 | 과거에 생산한 적이 없어 Capa가 가장 큰 호기에 넣음 | 호기가 맞는지 확인 |
   | 금형 충돌 | 같은 날 같은 금형이 두 호기에 배정됨 | 한쪽 날짜나 금형을 바꿈 |
   | 납기 내 수량 부족 | 납기까지 다 못 만듦 | 다른 호기로 나누거나 납기 조정 |
   | 금형 확인 필요 | 금형이 없거나 후보가 여럿 | 셀을 눌러 금형번호 선택 |
   | 교체유형 확인 필요 | 전환 이력이 없어 Full set으로 가정 | 셀을 눌러 B/M / Full 선택 |
   | 주문 품명 매칭 안 됨 | 기준정보에 없는 품명 | 주문 입력에서 제품 연결 |

4. 셀을 누르면 **금형번호**, 교체 유형, 배치 **근거**(예: "10/22 주 Rev 1 PET 7호기와 동일")가 보입니다. 점선 테두리는 자동 생성, 파란 점은 사람이 고친 셀입니다.
5. 시스템은 초안까지만 만듭니다. 확인이 끝나면 평소처럼 「확정 / 변경 저장」을 누릅니다. **Rev 이력**에서 자동 생성 셀 가운데 사람이 고친 비율을 볼 수 있습니다.

## 2-3. 재고현황 (작성자 입력, 조회자 열람·다운로드)

- **재고현황** 메뉴에서 월을 고릅니다. 품목은 구간(PS, 1211 …)과 호기별로 묶여 있고 접을 수 있습니다.
- 셀을 눌러 기초재고와 일자별 생산·출고를 고칩니다. 노란 칸은 저장 전 변경이며, 「저장」을 눌러야 반영됩니다. 현재고·포장수량·PT 수는 자동 계산입니다.
- 「엑셀 업로드」: 제품수불표를 고르면 **미리보기**(반영될 행 수, 새 품목, 매칭 안 된 품목, 경고)가 먼저 나옵니다. 연도는 파일에 없으니 확인하고 「확인」을 누릅니다. 같은 월을 다시 올리면 그 월 데이터를 통째로 바꿉니다.
- 「엑셀 다운로드」: 원본과 같은 모양으로 내려받습니다. 합계·현재고 등은 엑셀 수식입니다.
- 「계획 제품」 칸에서 수불표 품목을 생산계획 제품에 연결하면 그 재고가 **수급 검증**과 초안 생성의 순 소요량에 쓰입니다.

## 3. 금요일 확정과 주중 변경

- **확정**: 「확정 / 변경 저장」 버튼 → 첫 확정은 Rev 0으로 저장됩니다.
- **변경**: Rev 0 이후의 저장은 **변경 사유(구분 + 내용)를 입력해야** 저장됩니다. Rev 1, 2…로 쌓입니다.
- **Rev 이력** 메뉴에서 두 Rev를 골라 바뀐 셀을 비교합니다.
- 설비 고장 등 **가동 불가일**은 생산계획표 상단 「가동 불가 등록」에서 호기·기간·사유를 등록합니다. 해당 셀은 빗금 처리되고 생산량 0으로 계산됩니다.

## 4. 씨벌크 원료 (작성자)

- **씨벌크 원료** 메뉴: 사일로 합계 재고 6주 그래프(상한 160톤, 하한은 설정값). 1~2주는 계획, 3~6주는 운용안 추정입니다.
- **발주 추천 카드**: 하한 미달 예상일에서 리드타임(30일)을 뺀 발주 기한과 추천 물량(22톤 단위)이 표시됩니다. 발주는 사람이 합니다.
- 발주 후 **입고 일정 추가**에 공급사·입고 예정일·수량을 등록하면 그래프가 다시 계산됩니다.
- 아침 실측 재고는 「실측 입력」에서 사일로별로 기록합니다.
- 계획 대상이 아닌 사출 설비(A1, 2공장)의 사용량은 「외부 설비 사용량」에서 평일/주말 톤을 조정합니다.

## 5. 기준정보 (관리자)

- **기준정보** 메뉴: 제품(Capa·중량·안전재고·단위), 호기별 허용 금형, 호기×제품 Capa, 교체 손실 계수, 설정값(주말 계수, 교체 한도, 사일로 하한 등), 계정 역할.
- **제품배치 운용안 엑셀 업로드**로 제품·허용 금형·Capa·월별 물량을 일괄 등록합니다. 파일에 등장한 호기만 교체됩니다.
- 모든 수정은 수정자·시각이 감사 로그에 남습니다.

## 6. 계정·백업 (관리자)

- 계정 생성: 개발 PC에서 `npm run create-user -- 이메일 비밀번호 역할 이름`. 또는 Supabase 대시보드 → Authentication → Users → Add user 후 기준정보 화면에서 역할 지정.
- 백업: Supabase 자동 일일 백업. 수동 백업은 README「백업」 참고.
- 기준정보 변경 절차: 변경 요청 → 관리자가 화면에서 수정 → 생산계획표에서 재계산 결과 확인 → 필요 시 Rev 변경 저장(사유: 기타).

## 7. 자주 묻는 질문

| 질문 | 답 |
|---|---|
| 엑셀 가져오기에서 "매칭 실패" 셀이 나와요 | 기준정보의 제품명과 셀 글자가 다릅니다. 기준정보 제품명을 맞추거나 셀을 직접 입력하세요. |
| 사출기 행 숫자는 뭔가요 | 설비별 일일 원료(씨벌크) 소비량(톤)입니다. 생산배대 파일로 올리면 저장되고, 그 날짜의 씨벌크 사용량 계산에 쓰입니다. |
| 초안 자동 생성이 전부 "신규 제품"으로 나와요 | 참고할 과거 확정 계획이 없습니다. 생산배대를 먼저 가져오세요. |
| 새로 등록한 제품이 초안에 안 들어가요 | 새 제품은 Capa가 0입니다. 기준정보에서 Capa를 넣으세요. |
| 과잉이 너무 많이 떠요 | 기준정보 → 설정값 「과잉 기준 일수」(기본 14일) 또는 제품별 과잉 기준을 조정하세요. |
| 조회 계정으로 수정이 안 돼요 | 정상입니다. 조회 권한은 읽기 전용입니다. |
