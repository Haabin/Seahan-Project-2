## 개발 중 추가로 정한 규칙 (고객 확인 필요)

| 항목 | 적용 규칙 | 설정 |
|---|---|---|
| 계획 기준일 | "이번 주 목요일"(월~일 기준)부터 15일. 다른 목요일 선택 가능 | 화면 |
| 교체 횟수 집계 | 제품이 전일과 다르고 교체유형이 비어 있으면 교체로 세고 기본 교체유형 손실 적용 + "미입력, 기본값 적용" 주의. 제품이 같아도 교체유형이 입력돼 있으면 입력대로 | `default_changeover_type`=BM |
| 과잉 판정 | 예상재고 > 향후 N일 출고 합계. 제품별 재정의 가능. 향후 출고 0인 제품은 "출고 계획 없음" | `surplus_days`=14, `products.surplus_days` |
| 우선순위 점수 (FR-11) | w1·(1/(최초 부족까지 일수+1)) + w2·대형거래선 + w3·안전재고 미달 | `priority_weights` 3 / 2 / 1 |
| Capa 우선순위 | 호기×제품 Capa → 없으면 제품 기본 Capa | `line_product_capacity`, `products.default_daily_capa` |
| 3~6주 사일로 추정 | 월 운용안 물량 ÷ 가동일수 × 중량, 주말에는 주말 계수 적용 | `monthly_operation_plan`, `weekend_factor` |
| 사일로 2기 | 합계 기준으로 계산·그래프(상한 160t). 기별 실측치는 표에 표시 | – |
| 발주 추천 물량 | 최초 하한 미달일 − 리드타임 = 발주 기한. 리드타임 구간 최저 예상재고를 하한 위로 올리는 양을 입고 단위로 올림 | `lead_time_days`=30, `receipt_unit_ton`=22 |
