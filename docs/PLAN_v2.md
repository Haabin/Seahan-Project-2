## 4. 사용자가 해 줄 일 (M1 시작 시)

1. **GitHub**: `gh` CLI가 없음. 둘 중 하나
   - `winget install GitHub.cli` 후 `! gh auth login` (내가 저장소 생성·푸시)
   - 또는 GitHub에서 빈 저장소를 만들고 URL을 알려줌
2. **Git 사용자 정보** 미설정: 커밋에 쓸 이름·이메일을 알려주거나 `git config --global user.name/user.email` 실행
3. **Supabase**: 프로젝트 대시보드에서 아래 4개 값을 `.env.local`에 직접 입력 (프롬프트에 붙이지 않음)
   ```
   NEXT_PUBLIC_SUPABASE_URL=
   NEXT_PUBLIC_SUPABASE_ANON_KEY=
   SUPABASE_SERVICE_ROLE_KEY=
   DATABASE_URL=   # Settings → Database → Connection string (URI, Session pooler)
   ```
   내가 `.env.example`을 먼저 만들어 두면 그 파일을 복사해서 채우면 된다.
4. **Vercel**: 대시보드에서 GitHub 저장소 Import 후 위 환경변수 3개(`DATABASE_URL` 제외) 등록. 이후 push마다 자동 배포
