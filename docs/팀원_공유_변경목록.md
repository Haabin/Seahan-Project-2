# 팀원 공유 변경 목록

팀원이 같이 쓰는 파일(시드·DB 스크립트 등)의 동작이 바뀐 경우를 적는다. 실제 고객 데이터 값은 여기에 쓰지 않는다.

## 2026-11-19 · 실제 기준정보 보호 가드 (seed / reset)

**왜:** 개발 DB 에 현행 운용안 원본으로 기준정보를 넣은 경우(`npm run import:operation-plan`), `npm run db:seed` 가 PET 호기의 허용 금형·Capa·설비 상세를 가상 값으로 덮어쓰고 1STAGE 계획을 지운다. `db:reset` 은 전부 지운다.

**바뀐 파일**

| 파일 | 변경 |
|---|---|
| `scripts/db.ts` | `seed`·`reset` 전에 `settings.master_source` 를 확인. 값이 `"real"` 이면 멈추고 안내. `-- --force` 를 붙이면 실행 (`npm run db:seed -- --force`) |
| `scripts/make-fake-data.ts` → `supabase/seed.sql` | seed.sql 첫머리에 같은 가드(DO 블록)를 넣음. SQL 편집기로 직접 실행해도 막힌다. `--force` 실행 시 db.ts 가 `set local app.seed_force = 'on'` 으로 통과시킨다. 끝에서 `master_source = "fake"` 로 표시 |
| `package.json` | `import:operation-plan` 스크립트 추가 |

**팀원이 할 일**

- 가상 데이터만 쓰는 DB 라면 할 일 없음. `master_source` 가 없거나 `"fake"` 면 예전과 똑같이 동작한다.
- `seed.sql` 은 계속 `npm run fake-data` 로 생성한다(직접 편집 금지). 가드는 생성기에 들어 있다.
- 실제 기준정보가 있는 DB 에서 정말 가상 데이터로 되돌리려면 `--force`. 되돌린 뒤 다시 실제 값을 넣으려면 로컬 미리보기 JSON 으로 `npm run import:operation-plan -- --apply <json>`.

## 2026-11-19 · 현행 운용안 원본 양식 파서 (새 파일, 기존 파일 동작 변화 없음)

- `lib/excel/import-operation-plan.ts` · 2줄 헤더, 호기·생산설비 아래 채움, 소계·합계 건너뜀, Capa 수식 계산값 내림(본/일)
- `lib/excel/product-code.ts` · 제품명 정리와 제품코드(`RP-` + 이름 해시 8자리) 규칙. 회사 품번을 쓰게 되면 이 파일만 바꾼다
- `lib/data/demo-plan.ts` · 허용 금형으로 데모 계획 셀 생성
- `scripts/import-operation-plan.ts` · 미리보기(DB 읽기만) → `--apply <미리보기 JSON>` 쓰기
  - 쓰기 때 기존 F1·1STAGE 계획을 지우고 데모 초안을 만든다. 지울 계획에 **확정 Rev** 가 있으면 기본으로 멈춘다.
  - `--allow-delete-confirmed` 를 붙였을 때만 삭제 구간에서 NFR-09 불변 트리거(`plan_cells_immutable`, `plan_revisions_immutable`)를 잠시 끄고 지운 뒤 다시 켠다(한 트랜잭션).
  - ⚠ **이 플래그는 개발 DB 전용이다. 운영 DB 에서는 절대 쓰지 않는다.** 확정 Rev 는 이력 보관 대상(NFR-09)이다.
- 기존 `import-master.ts`(우리 양식)와 `/api/import/master` 는 그대로다.
- 실제 설비 제조사 규칙·미리보기 JSON 은 `data/samples/`(gitignore)에만 둔다. 저장소에 올리지 않는다.

## 2026-11-19 · 데모 계획이 다운타임을 피함 + 데모 계획만 다시 만들기

| 파일 | 변경 |
|---|---|
| `lib/data/demo-plan.ts` | 다운타임 날짜에는 셀을 만들지 않음. 교체유형을 호기마다 BM → FULL → 미입력 순으로 돌려 세 가지 배지가 모두 보이게 함. 다운타임 다음 날 교체는 명시 유형 |
| `scripts/regenerate-demo-plan.ts` (새 파일) | 최근(또는 `--period`) F1·1STAGE 계획의 **초안 1건의 셀만** 다시 만든다. 미리보기(DB 읽기만) → `--apply <미리보기 JSON>` |
| `scripts/import-operation-plan.ts` | 데모 계획 생성 시 다운타임 반영 |
| `package.json` | `demo-plan:regenerate` 스크립트 추가 |

- 확정 Rev 가 있는 계획, 초안이 1건이 아닌 계획에서는 멈춘다. 미리보기 이후 계획·초안·허용 금형·다운타임이 바뀌어도 멈춘다.
- 기준정보·다른 계획은 쓰지 않는다. 미리보기 JSON 은 `data/samples/import-preview/`(gitignore)에 저장된다.
